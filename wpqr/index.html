📁 Thư viện WPQR / PQR

Hồ sơ chứng nhận quy trình hàn — gom từ dữ liệu WPS
Danh mục PQR được trích tự động từ 75 WPS trong thư viện: mỗi PQR liệt kê các WPS dựa trên nó. Bấm WPS để mở chi tiết (cần mật khẩu nội bộ như Thư viện WPS). File PDF PQR gốc lưu tại hồ sơ QC — muốn nhúng vào app, bỏ file vào webapp/wpqr/files/ và đặt tên theo số PQR.
