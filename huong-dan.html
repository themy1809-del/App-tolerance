2

Đăng lên đường link (chọn 1 trong 3)

🚀 Cách A: Netlify Drop KHUYẾN NGHỊ · 1 PHÚT

Vào app.netlify.com/drop → kéo-thả nguyên thư mục webapp vào trang. Netlify tạo HTTPS link ngay (vd https://daidung-tools.netlify.app) → chia sẻ link cho cả đội.

✓ Miễn phí · ✓ HTTPS tự động · ✓ Custom domain · ✓ CDN toàn cầu

📦 Cách B: GitHub Pages MIỄN PHÍ

Đẩy thư mục webapp lên repo GitHub → bật Settings → Pages → link dạng https://<user>.github.io/<repo>. Có HTTPS sẵn.

Đã có sẵn script Cap-nhat-GitHub.bat để auto add + commit + push.

🏢 Cách C: Máy chủ nội bộ công ty (IIS / Apache / Nginx)

Copy webapp/ vào thư mục web. Dùng trong mạng LAN. Có thể chạy không HTTPS nội bộ nhưng cài PWA cần HTTPS.

➕
+ Thêm dòng hoặc ✏ Sửa / 🗑 Xoá dòng có sẵn.

Khi gặp vấn đề

🔄 App không cập nhật mặc dù đã push

Service Worker đang cache version cũ. Mở reset.html → trang tự xoá SW + cache → redirect về home → F5.

📥 Cap-nhat-GitHub.bat lỗi "index.lock"

Đã có patch auto xoá .git/index.lock + .git/HEAD.lock trước khi pull/push. Nếu vẫn lỗi, đóng GitHub Desktop / VS Code source control rồi chạy lại.

⬜ Trang trắng / scripts không chạy

Mở DevTools (F12) → Console — xem lỗi JS. Hard reload bằng Ctrl+Shift+R. Nếu vẫn lỗi, vào reset.html.
