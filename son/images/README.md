# Ảnh thật cho module QC Sơn

Lưu ảnh thật vào folder này với tên = **id của lỗi sơn** + `.jpg`, app tự hiển thị trong tab Lỗi sơn.

## Danh sách id (tab Lỗi sơn)

| File | Lỗi |
|---|---|
| `sag.jpg` | Chảy sơn (Sagging/Runs) |
| `orange.jpg` | Da cam (Orange peel) |
| `pinhole.jpg` | Lỗ kim (Pinholes) |
| `crater.jpg` | Mắt cá (Fish eyes/Cratering) |
| `blister.jpg` | Phồng rộp (Blistering) |
| `crack.jpg` | Nứt màng (Cracking) |
| `flake.jpg` | Bong tróc (Flaking) |
| `rust_rash.jpg` | Gỉ điểm xuyên màng |
| `dryspray.jpg` | Phun khô (Dry spray) |
| `overspray.jpg` | Bụi sơn bám (Overspray) |
| `popping.jpg` | Nổ dung môi (Solvent popping) |
| `wrinkle.jpg` | Nhăn màng (Wrinkling) |
| `chalk.jpg` | Phấn hóa (Chalking) |
| `amine.jpg` | Mồ hôi amine (Amine blush) |
| `zincsalt.jpg` | Muối kẽm (White rust) |
| `lowdft.jpg` | DFT thiếu/quá dày (ảnh máy đo DFT) |

## Gợi ý
- Nút "🔍 Google Images / Bing Images" trong từng lỗi đã có từ khóa tìm sẵn.
- Ảnh tự chụp tại xưởng là tốt nhất (không vướng bản quyền).
- JPG, ≤ 300KB/ảnh.
