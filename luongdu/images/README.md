# Folder lưu ảnh thật

Đặt ảnh JPG/PNG vào đây với tên theo `id` của defect trong gallery.js.

**Ví dụ:**
- `undercut.jpg` → ảnh defect "Cháy chân"
- `p-blister.jpg` → ảnh "Phồng sơn"
- `d-caliper.png` → ảnh "Caliper điện tử"

**Cách lấy ảnh:**
1. Click button "🔍 Google Images" hoặc "🔍 Bing Images" trên app
2. Browser mở tab mới với search query có sẵn
3. Save ảnh ưng ý xuống máy
4. Đổi tên thành `<id>.jpg` rồi copy vào folder này
5. Push lên GitHub — app sẽ tự ưu tiên dùng ảnh local thay vì search button

**Định dạng được hỗ trợ:** `.jpg`, `.jpeg`, `.png`, `.webp`
